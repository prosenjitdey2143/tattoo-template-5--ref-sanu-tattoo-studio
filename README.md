# Midnight Moon — Premium Tattoo Studio

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Aesthetics](https://img.shields.io/badge/Aesthetics-Premium-red.svg)
![Animations](https://img.shields.io/badge/Animations-GSAP-green.svg)

Midnight Moon is a high-end, cinematic tattoo studio web application designed to provide a premium user experience. It features sophisticated animations, infinite portfolio scrolls, and a sleek dark-themed aesthetic tailored for the modern body art industry.

## ✨ Features

- **Cinematic Hero Section**: Dynamic video and image slider with GSAP-powered transitions and text animations.
- **Infinite Portfolio Scroll**: A seamless, horizontally scrolling marquee showcasing the studio's best work.
- **Interactive Studio Reels**: A tactile video reel slider built with Swiper.js for engaging content exploration.
- **Service Showcase**: Detailed breakdown of services including Custom Tattoos, Piercings, and Aftercare.
- **Testimonial Module**: Client stories integrated with a video experience for social proof.
- **Premium UI/UX**: Custom cursor, glassmorphic elements, smooth scrolling, and responsive design.
- **Modern Typography**: A curated mix of *Playfair Display*, *Inter*, and *Cormorant Garamond*.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Animations**: [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- **Sliders**: [Swiper.js](https://swiperjs.com/)
- **Icons & Graphics**: Custom SVG paths and icons.
- **Fonts**: [Google Fonts](https://fonts.google.com/)

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser to view the project.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/prosenjitdey2143/tattoo-template-5--ref-sanu-tattoo-studio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd tattoo-template-5--ref-sanu-tattoo-studio
   ```
3. Open `index.html` in your browser.

## 🎨 Design Philosophy

Midnight Moon focuses on "Cinematic Ink Experiences." The design uses a deep charcoal and red color palette, evoking a sense of mystery and craftsmanship. The use of rotating rings and crosshair elements symbolizes the precision of the tattoo artist.
